# Local investor demo data

From the backend checkout, run `bash scripts/investor-demo/setup.sh` with Docker Compose, Node dependencies and OpenSSL installed. The script starts its own MySQL service on loopback port 3360, applies this checkout’s ordinary migrations, and seeds one transaction. To rebuild the synthetic database, run `bash scripts/investor-demo/setup.sh reset`. Stop any demo API before resetting. A second seed on populated data refuses to overwrite it.

Connection settings and generated Maya/Admin passwords are in the ignored, private `.investor-demo/local.env`. The fixture accounts are maya.demo@example.invalid and admin.demo@example.invalid. The other synthetic users have no distributed password. No payment or mail APIs are invoked. Use a separate demo API/working directory, upload store and Qdrant collections when attaching the frontend; do not point a demo API at the working database or search index.

Brighton v1 originates from the styleguide’s fabricated Brighton address list and John Doe ledger. Stable source keys use properties.source_ref. The investor_demo portfolio_record facts preserve the original property type, listed document names and demo provenance. Ledger entries retain source dates, amounts, vendors and payment states. Listed documents have no invented binaries or vectors. Maya’s PDFs are parsed into private document records; vector indexing is a separate app operation. The manufacturer manual is downloaded from Bosch and hash-checked, outside Git. The schema fingerprint covers table definitions, keys and constraints and excludes next auto-increment values.

Start the isolated product API with `bash scripts/investor-demo/start-api.sh`. It listens on 127.0.0.1:8360 and uses a fresh signing secret on each start. Run `node scripts/investor-demo/verify-api.js` against that process to check real login, admin-only access, portfolio totals, plan filters, dataset boundaries and John’s ledger. Configure the investor frontend proxy to use port 8360. This launcher is for the Data Room rehearsal. External integrations are disabled and vector retrieval requires a separately provisioned local index.
